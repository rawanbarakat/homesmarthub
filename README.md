# Smart Picks Hub — website starter

This is a responsive static website starter for an independent home-and-kitchen buying guide website aimed at UAE readers.

## Files
- `index.html` — homepage
- `guides.html` — article directory
- `articles/` — 10 original starter guides
- `about.html`, `contact.html`, `affiliate-disclosure.html`, `privacy.html` — supporting pages
- `styles.css` — responsive styling

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `contact.html` with an email address you control, or link to a contact form.
2. Review the Privacy Policy so it accurately reflects your hosting provider and any tools you add.
3. Read Amazon.ae Associates policies and ensure every affiliate link is properly tagged.
4. Do not add invented product prices, reviews, ratings, or claims of personal testing.
5. Add real product recommendations only after checking current product information. Put a clear “paid link” or equivalent notice near affiliate links.
6. Keep publishing genuinely useful original content and update articles as needed.
7. Verify the live site on mobile and desktop.

## Publish with GitHub Pages (free static hosting)
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository. You can name it `smart-picks-hub` (for a project site) or `YOURUSERNAME.github.io` (for a user site).
3. Upload the files and folders from this ZIP, preserving the folder structure. The `index.html` file must be at the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**. Choose the `main` branch and `/ (root)`, then save.
6. Wait for deployment and open the site URL shown in the Pages settings. It may take several minutes.
7. Test every page and link. Your free address will be based on your GitHub username/repository. You can add a custom domain later if you wish.

Official guide: https://docs.github.com/en/pages/quickstart

## Amazon Associates application checklist
- Apply for the Amazon.ae program using the official Associates Central website: https://affiliate-program.amazon.ae/
- Enter the exact public URL of the site you own and have published.
- Use accurate account and payment/tax details.
- Ensure the site is accessible without login and has original, helpful content.
- Amazon.ae's published review guidance says it generally looks for at least 10 posts, recent content, and at least three qualifying sales within the first 180 days after signup; personal orders do not qualify. Check the latest official guidance because requirements can change.
- Use Amazon-provided tagged links once you have access and make sure the tracking ID matches the marketplace.
- Include the required statement: “As an Amazon Associate I earn from qualifying purchases.”
- Clearly disclose affiliate links near recommendations.
- Do not suggest Amazon endorses your site. Follow Amazon's current trademark, content, link, and product-content policies.
